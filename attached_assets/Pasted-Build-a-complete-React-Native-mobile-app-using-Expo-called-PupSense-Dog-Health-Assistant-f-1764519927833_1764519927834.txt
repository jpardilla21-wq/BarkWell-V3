## Design system (important – follow this)

### Colors

Define these in `src/theme/colors.ts` and use them consistently:

- `primaryBlue: "#4A7BFF"`
- `primaryGradientStart: "#4A7BFF"`
- `primaryGradientEnd: "#6ED2FF"`
- `softGreen: "#6ED29B"`
- `warningYellow: "#FFD95F"`
- `urgentRed: "#FF6B6B"`
- `background: "#F6F6F6"`
- `cardBackground: "#FFFFFF"`
- `textDark: "#1E1E1E"`
- `textMuted: "#6E6E6E"`
- `borderLight: "#E5E5E5"`

For risk levels:

- Low: `softGreen`
- Medium: `warningYellow`
- High: `urgentRed`

### Typography

Define typography tokens in `src/theme/typography.ts`:

- Use React Native default fonts but simulate:

  - `headingL`: fontSize 28, fontWeight "700"
  - `headingM`: fontSize 22, fontWeight "600"
  - `headingS`: fontSize 18, fontWeight "600"
  - `bodyM`: fontSize 16, fontWeight "400"
  - `bodyS`: fontSize 14, fontWeight "400"
  - `label`: fontSize 13, fontWeight "500"

Use these via a shared `Text` component or style objects.

### Layout & spacing

Create `spacing.ts`:

- `xs: 4`
- `sm: 8`
- `md: 16`
- `lg: 24`
- `xl: 32`

All screens should:

- Use `SafeAreaView`.
- Use padding `md` or `lg`.
- Use card-like containers with `borderRadius: 16`–`20`, `backgroundColor: cardBackground`, and a soft shadow (e.g., `elevation` or `shadowColor`, `shadowOpacity`, etc).

- `backgroundColor: primaryBlue`
- Centered white label.
- Optional `variant="secondary"` for outlined button later.

### `TextInputField`

- Label above.
- Rounded corners.
- `borderColor: borderLight`, `borderWidth: 1`.
- Padding inside.
- Supports `multiline`.
